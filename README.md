## 🚀 Key Features

1. **Bilingual Experience (Arabic & English)**:
   - Full native RTL support with Cairo Arabic typography.
   - Fluid LTR support with Inter English typography.
   - Instant language switching preserving the active context.

2. **First-Class Theme System**:
   - Modern Dark Studio Theme (`#10141D` background with violet/blue accents).
   - Clean Light Executive Theme (`#F7F8FC` background with indigo accents).
   - Saved visitor preferences in `localStorage`.

3. **Authentic Photography & Identity**:
   - High-definition portrait integration preserving 100% of authentic facial features.
   - Hero floating cards, verified IT graduation badge, and active specialties rotator.

4. **Production Projects Showcase**:
   - **Hisabi (حِسابي)**: Comprehensive Financial, Debt Ledger & Multi-Tier Backup Platform.
   - **UMCO Pharmaceuticals Platform**: Bilingual Enterprise Medical Web Platform.
   - **CarX**: Automotive Marketplace & Workshop Booking Platform.
   - **PharmaLeaf AI**: Intelligent Medical Leaflet OCR & Column Layout Analysis.
   - **PharmaLeaf Studio**: Web-based Industrial Print & Vector Leaflet Designer.
   - **Brand-Testing**: Arabic-first SVG Logo Color Studio & Export Tool.
   - **Formora 3D**: Real-Time 3D Packaging Design Studio.
   - **Agriculture ERP**: Clean Architecture ERP Dashboard (Flutter & ASP.NET Core 8).

5. **Interactive Online CV & Instant PDF Generation**:
   - Recruiter-ready formatted CV preview in both Arabic and English.
   - Native browser printing and PDF generation formatted to standard A4 specifications.

6. **Private Content Management Dashboard (CMS)**:
   - Password-protected administrative login at `/admin` (or via Admin trigger in the navbar).
   - Live editing of profile, bio, titles, and contact information.
   - Project and experience management.
   - Visitor inquiries inbox with direct reply actions.
   - Full JSON snapshot export and import for seamless zero-loss backups.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: CSS Custom Properties & Semantic Design Tokens (Tailwind-compatible)
- **Icons**: Lucide React + Custom SVG Vectors
- **Typography**: Google Fonts (Cairo for Arabic, Inter for English, Fira Code for Monospace)
- **Hosting & CI/CD**: GitHub Pages via automated GitHub Actions (`.github/workflows/deploy.yml`)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/En-Dhiaa/dhiaa-portfolio.git

# Navigate to project folder
cd dhiaa-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
